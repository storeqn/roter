# نظام تتبع الدلفري

نسخة أولية لمتابعة موقع سائقي التوصيل مباشرة.

## الصفحات
- index.html الصفحة الرئيسية
- driver.html صفحة الدلفري
- admin.html لوحة المطعم

## قبل التشغيل
أنشئ مشروع Firebase وفعّل Realtime Database، ثم ضع firebaseConfig داخل firebase-config.js.

## ملاحظة
تتبّع الموقع من المتصفح قد يتوقف عند قفل الشاشة أو وضع الصفحة في الخلفية، خصوصًا على iPhone.
